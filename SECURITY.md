# Security

Do not include network passwords, personal documents or session contents in bug
reports. Redact SSIDs and addresses when they are unnecessary to reproduce a bug.

For a suspected vulnerability, avoid posting exploit details in a public issue.
Once the hosted repository enables private vulnerability reporting, use its
Security tab. Until then, contact the repository maintainer privately through the
channel where you obtained the build. No public reporting mailbox is configured.

The current release candidate has not received a dedicated security audit.
