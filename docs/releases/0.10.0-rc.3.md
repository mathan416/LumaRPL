# LumaRPL 0.10.0-rc.3

Release candidate for PicoCalc with Pico 2 W and UF2 Loader v2.4.1.

## Changes

- Complete calculator FFT/InvFFT, distribution probabilities and inverse quantiles, real-matrix factorizations/analysis, modular reduction and bounded symbolic transformations.
- Add one-time clock reminders: schedule, list, recall/find, acknowledge and delete alarms. Reminders use the local clock and are included in saved calculator sessions.
- Add complex Gamma/factorial, native imaginary-unit entry and exact Termial (`?`). Improve immediate operator entry, grouped formulas, partial cursor redraw and error recovery.
- Restore the parent menu's page and selected row when returning from submenus. Connect supported calculator menu actions and hide unavailable inherited interfaces.
- Correct numerical accuracy and runtime issues found during the review and sanitizer checks.
- Refresh built-in help and all three manuals, including the Lua/API and CHIP-8/SUPER-CHIP reference.

See `docs/CALCULATOR-CAPABILITIES.md` for supported domains and limits. Matrix decompositions currently accept real matrices, FFT lengths are powers of two up to 1024 subject to memory, and alarms are one-time visual reminders without powered-off wake-up.

## Verification

The calculator runtime is unchanged from the tested `06f36d7` source. The patched full simulator suite passes 8,507 checks with zero failures and assertions. The 135 calculator contract checks pass normally and under address/undefined-behaviour sanitizers. Fresh normal/sanitized controllers cover 325 screen IDs and eight themes; bounded host tests, Lua, Arm allocation/TLS, 310 help examples and 135 manual examples pass.

The fresh pristine-upstream comparison and its known baseline-only sentinel-pointer assertions are documented in `docs/review/release-evidence.json` and `docs/review/rc3/`. Additional calculator registrations/regressions extend the patched test count.

The user confirmed working time/alarms, successful save/restart with alarm restoration, and a 30-minute mixed-use session without issues on the predecessor image. This candidate changes version metadata, manuals and release tooling. Cold boot of the exact newly versioned rc.3 image remains an installation check.

## Downloads and installation

Use **LumaRPL-SD.zip** for firmware plus resources, or **LumaRPL-Pico-2-W.uf2** for firmware alone. Verify downloads with **SHA256SUMS**. The three PDF manuals are also available separately.

Save your session and back up the card. Replace `pico2-apps/LumaRPL-Pico-2-W.uf2` and merge the supplied `db48x/` resources, preserving existing configuration, sessions, credentials, edited examples and documents. Keep the existing bootloader and other applications. Safely eject the card, return it to PicoCalc and select LumaRPL.

Open alarms directly with `AlarmMenu` Enter, or through MainMenu → Time → Alarms.

**LumaRPL-source.tar.gz** contains the corresponding application and complete pinned dependency sources. **SOURCE.json**, **UF2.json**, **MEMORY.json** and **VERIFICATION.json** record source/build provenance and verification scope. This is a prerelease candidate.
