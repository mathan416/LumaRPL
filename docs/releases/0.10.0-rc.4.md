# LumaRPL 0.10.0-rc.4

Release candidate for PicoCalc with Pico 2 W and UF2 Loader v2.4.1.

## Changes

- Calculator entry: a typed power keeps a leading minus with its number, as on the RPN keys (`-2^2` gives 4; use `(-(2^2))` for -4). Operator keys no longer change a hidden entry while help, graphics or stack browsing is shown.
- Alarms: Enter acknowledges a reminder; Esc/Back or a one-minute timeout snoozes reminders for five minutes. Idle checks never raise errors, and back off after a failed draw or save.
- Lua: F5 is an ordinary key that scripts can read; only Esc interrupts. Esc now also interrupts long string pattern searches. `load` accepts source text only and `string.dump` is removed.
- Editors and tools: Replace all is fully undoable up to eight matches and asks before larger replacements. CHIP-8 assembler numbers with leading zeros are decimal, and `0b` binary is accepted. ODE examples ask before replacing unsaved work.
- Storage and devices: failed saves remove their temporary files. Startup reports when a damaged session was replaced by its previous copy. SD v1 card detection, large-card sector counts, PSRAM transfer timing, key press/release pairing and alarm timing statistics are fixed.
- Release tooling: packages committed content only, verifies the `db48x` tree against the patch, keeps checks active under optimized Python and runs simulator tests in isolated folders.
- Manuals: all three PDF manuals are rebuilt for these changes.

See `docs/CALCULATOR-CAPABILITIES.md` for supported domains and limits.

## Downloads and installation

Use **LumaRPL-SD.zip** for firmware plus resources, or **LumaRPL-Pico-2-W.uf2** for firmware alone. Verify downloads with **SHA256SUMS**. The three PDF manuals are also available separately.

Save your session and back up the card. Replace `pico2-apps/LumaRPL-Pico-2-W.uf2` and merge the supplied `db48x/` resources, preserving existing configuration, sessions, credentials, edited examples and documents. Keep the existing bootloader and other applications. Safely eject the card, return it to PicoCalc and select LumaRPL.

**LumaRPL-source.tar.gz** contains the corresponding application and complete pinned dependency sources. **SOURCE.json**, **UF2.json**, **MEMORY.json** and **VERIFICATION.json** record source/build provenance and verification scope. This is a prerelease candidate.
