# Manual artwork

cover-photo.jpg is the user-supplied IMG_8543.jpeg, oriented using its camera
metadata and re-encoded without EXIF metadata. The PDF renderer crops it within
the cover frame. Photograph supplied by Iain Bennett for these manuals; software
license grants do not assign ownership of the photograph.

Other PNGs are authentic 320x320 host renders of production LumaRPL controllers,
from the release-candidate controller run. They are labelled as host renders in
the manuals. They are not photographs or claims of physical-device acceptance.
