# LumaRPL port 19.11 — Esc menu navigation

On calculator soft-menu screens, Esc returns one menu level. At the top-level menu it clears the menu. For example: Ctrl+R → Angles → Esc returns to Advanced RPL settings; another Esc clears it. LASTMENU remains available as the upstream history command, but is no longer needed for normal Back navigation.

Parent menu pages are restored; returned menus start on their normal Tab row. F1–F5 and Ctrl+F5 retain their column mappings. Ctrl+A, Ctrl+R and the corresponding Home actions open a fresh menu tree, so Back never enters an unrelated previous tool.

Esc dismisses an error before navigating. Unfinished calculator input survives menu navigation and clearing; with no menu open, another Esc cancels that input. Help, graphics, interactive stack controls and native tools retain their existing Esc behavior. Held/repeated Esc cannot skip menu levels.

The obsolete ExitMenu UI toggle is hidden on PicoCalc. Its saved flag and RPL commands remain compatible, but cannot disable this Back behavior. Help documents this distinction.

Navigation consumes the existing eight-entry upstream history instead of rotating it. It allocates no new state; older ancestors beyond that bounded history are discarded. The 208 KiB calculator arena, 96 KiB heap, 32 KiB stack, 100 KiB framebuffer and 16 KiB workspace remain unchanged.
