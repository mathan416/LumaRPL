# LumaRPL port 19.10 — calculator menu shortcuts

- **Ctrl+A:** Command Catalogue.
- **Ctrl+R:** Advanced RPL settings.

These shortcuts work on the calculator screen, including during command entry. Opening either menu preserves the working entry and stack. They use the same menu-opening functions as Home. Tab selects a row, F1–F5 select columns 1–5, and Ctrl+F5 selects column six. Esc closes the menu. The shortcuts do not switch away from the command-reference reader or full-screen graphics.

Source editors read their own raw key events: Ctrl+A remains Select all and Ctrl+R remains Replace. Formula prompts retain their existing Ctrl+A replacement behavior. Held Ctrl keys are excluded from hardware autorepeat; the existing transition gate blocks repeated activation until release.

The Keyboard shortcuts page and the Keys & menus reference topic document the new bindings. Other native Help topics and the DB48X command-reference content are unchanged. All prior fixes, including port19.9 compact soft-key labels, are included.
