# LumaRPL port 19.7 — PicoCalc command reference

The DB48X command reference now contains a PicoCalc edition of the manual, its own regenerated byte-offset index, corrected navigation links and mathematical figures fitted to the 320×320 display. It replaces the upstream manual at `/db48x/help/db48x.md`; it is the same entry under Calculator reference, not another help book to hunt for.

The other Help topics, menu Details, shortcuts page and credits are unchanged. The build verifies their files against port 19.6. Mathematical/RPL code examples from the retained command chapters are preserved and checked automatically. Hardware-only tutorials and physical-key access sequences are replaced with actual PicoCalc instructions. Legacy unsupported device commands are identified explicitly; they are not advertised as working calculator features.

The PicoCalc reader omits upstream keypad access hints, retains literal command spellings and uses proportional prose with compact fixed-cell code. Wide tables are presented as full-width records. A reference-only font extends the compact face with the mathematical glyphs this book needs; the native UI font is unchanged. This targets the DB48X reader; the existing native Help remains unchanged.

## Reader controls

- Ctrl+K: find a command or topic by name, such as SIN, Integrate, Modes, StackFont or Elastic Buckling. Ordinary-space spellings are supplied for typographic topic names. Cancel leaves the current topic and calculator input intact.
- F1: contents; F2/F3: page up/down.
- Left/Right or F4/F5: previous/next link; Enter: follow it.
- Backspace or Ctrl+F5: previous topic; Esc: close the reference.
- Enter on a selected fenced example inserts its source into the calculator entry; it does not run it. Finish/cancel prior text first to insert the example alone.

The reference retains its labelled six-column RPL controls; F5 means next link here. Other Help/native pages keep their existing five-slot controls. Typing letters/numbers while reading no longer changes calculator input behind the reference.

## Shift and alpha

The DB48X engine has normal, left-shift and right-shift command planes, plus uppercase/lowercase alpha states. Tab selects those three rows in calculator soft menus; F1–F5 and Ctrl+F5 select their six columns. Enter, editing and arithmetic keep normal meanings when a menu row is selected.

PicoCalc's physical Shift and Caps Lock control QWERTY typing. QWERTY text does not require HP-style alpha mode, and this port is not an HP48 letter-labelled keypad. UILeftShift, UIRightShift, UINoShift, UIAlpha, UILowercase and UINoAlpha retain engine-state semantics; their reference entries explain the distinction from numerical bit shifts and physical text input.

## Device checks after deployment

1. Help & about > Calculator reference > DB48X command reference: expect the LumaRPL/PicoCalc introduction, not a DM42 hardware tutorial.
2. Use F2/F3 to scroll and Left/Right then Enter to follow a link. Backspace and Ctrl+F5 should go back; Esc closes the reader.
3. Ctrl+K, enter SIN, then Enter: read the sine command. Repeat for Modes, StackFont and Elastic Buckling. Follow the ordinary-space topic link to the mathematical figure; it should fit horizontally.
4. Search BatteryVoltage, ScreenCapture or USBRECV: read the PicoCalc compatibility note and the appropriate native alternative.
5. Leave a value on the stack and unfinished calculator text before opening the reader. Scroll, type ordinary letters while viewing, cancel a search, and close the reader: the value and entry must be unchanged.
6. Check an existing native Help topic and Details page: presentation and content should be unchanged.

Four mission trajectory images (ETMB1–4) are absent from the pinned upstream sources. Their entries retain the RPL examples and identify that limitation rather than linking to missing files. Other referenced mathematical figures are bundled and bounded to 300 pixels wide.

Host/build/visual evidence is separate from physical acceptance. No SD deployment is performed by building this release.

## Memory measurement

The Arm build uses 1,948,048 bytes of the 4,186,112-byte loader application partition. Static RAM before heap is 387,536 bytes (316 fewer than port 19.6). The 208 KiB calculator arena, 96 KiB heap, 32 KiB stack, 100 KiB framebuffer and 16 KiB shared workspace are unchanged; 5,680 bytes remain between bounded regions.

The loader-facing firmware filename is `LumaRPL-Pico-2-W.uf2`. This naming update changes no firmware bytes. Internal build targets retain their DB48X names.
