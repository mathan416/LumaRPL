# LumaRPL port 19.13 — consistent Help throughout

The built-in eleven-topic guide, twelve native tool help pages, menu Details and full PicoCalc command reference now distinguish physical keys, on-screen actions, typed RPL commands, argument-taking settings, argument-free choices/flags, SD library calls and unavailable upstream names. RPL virtual editor commands are explicitly separate from the native SD source editor. Physical entry preserves an open menu's selected Tab row around typed UI-state commands, so ordinary row changes use Tab. Lua APIs and console directives are identified as Lua interfaces, not RPL commands.

The reference derives its classifications from the actual target opcode declarations and shipped SD library configuration. All 1,026 parseable built-in commands have indexed entries, including their accepted spellings. The index prioritizes full explanations over aliases; tested Fix/FixedDisplay, Grad/Grads and Prec/Precision lookups cannot loop through redirects. Missing command entries receive purpose descriptions; value settings explain their required stack input. Angle presets remain selected until another is chosen. Typed on/off flag commands select a state, while the corresponding calculator soft keys toggle it. Display digit settings and calculation precision are distinct.

Legacy SD/USB, user-font-installation and other absent names are qualified instead of presented as working built-ins. SD library entries show the library marker and their SD dependency. Earlier RGB332-pattern wording is corrected: RPL serialized drawing patterns remain RGB565 and are quantized for the RGB332 display, preserving saved formats. HeaderFont retains a compatibility value while PicoCalc headers stay compact. SystemMemory and PowerVoltage do not supply actual PicoCalc free memory or measured supply voltage; use Device status instead.

Native tool Help now comes from docs/ui/tool-help.json, compiled into flash through the shared generator. Source-editor shortcuts, Lua console syntax, formula fields and on-screen actions have distinct descriptions. Menu Details retain their selected values and contextual explanations. Native mathematical behavior, saved formats, network implementation, arena/heap/stack/framebuffer/workspace reservations and credits are unchanged.

## Verification and limits

Fresh tests check every command and spelling against the source declarations, source hashes, index offsets, internal links, all referenced figure files and complete font glyph coverage. Original fenced mathematical examples remain intact. Production engine tests execute the documented arithmetic, Fix/Precision, repeated Grads selection, Beep and font-setting examples. Production controllers cover all 173 screen paths in eight themes, with all built-in/tool help bodies rendered through the actual reader and scripted paging/Back. Visual review covers every native help family plus representative command roles, as recorded in the scoped UI report. This is not a claim that every mathematical exposition was independently proofread or every command physically tested.

The unchanged engine/font baseline retains the clean 8,447-test desktop result from port 19.8; it is explicitly inherited rather than a fresh full-suite run. Fresh Arm memory, resource, rendering and UF2 Loader v2.4.1 checks accompany this build. Physical-device Help navigation and readability acceptance remain pending.

## Device checks

Read Help & about > Calculator reference, then the tool-specific Help pages. Check Advanced RPL settings explanations, Lua versus RPL entry, and source-editor shortcuts. In the command reader use Ctrl+K for Fix/FixedDisplay, Grads, BeepOn, HeaderFont, Foreground, GEVPDF, SDREADLINE and FNTSTK. Check display aliases and follow their links. Esc leaves the reader; Enter on a highlighted example inserts source rather than executing it.

This release includes the quiet startup clock and Esc Back work from ports 19.12/19.11. SD deployment remains a separate action and has not been performed by this build.
